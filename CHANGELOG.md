# Changelog

## 0.1.0 - Initial release

- Offline JSON language packs for Ukrainian, Simplified Chinese, German, French, Spanish, Italian, Turkish, Brazilian Portuguese and Hungarian.
- Language selection in the game settings and an F8 menu with pack reloading.
- Context-sensitive translations, dynamic text rules and support for additional character sets.
- Optional localized map previews and fallback to original game text.
- Translation template, format documentation, validation tools and release build script.
